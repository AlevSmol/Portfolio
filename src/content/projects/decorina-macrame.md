El sistema Decorina Macramé es una aplicación web desarrollada para apoyar la gestión integral del emprendimiento de enseñanza y venta de productos artesanales “Decorina Macramé”, perteneciente a la emprendedora Maira Cáceres Molina.
El sistema busca optimizar la administración de inventario, cursos, insumos y registro de participantes, permitiendo un control automatizado de los procesos comerciales y educativos que actualmente se ejecutan de forma manual o dispersa.
<h3 className="text-dark">
Razones para su desarrollo
</h3>
El desarrollo del sistema surge de la necesidad de centralizar la información operativa del emprendimiento y reducir la dependencia de registros manuales o planillas dispersas.
Entre las principales motivaciones se encuentran:

    o	Mejorar la eficiencia operativa mediante la automatización de tareas repetitivas.
    o	Evitar pérdida de información por errores humanos.
    o	Facilitar la visualización del stock y las reservas de materiales.
<h3 className="text-dark">
Alcance
</h3>
El sistema Decorina Macramé tiene como propósito brindar una solución tecnológica centralizada para la administración de los procesos operativos del emprendimiento, con énfasis en la gestión de inventario, control de cursos, registro de participantes y autenticación de usuarios.
El alcance se limita al desarrollo e implementación de una plataforma web funcional, que pueda ser accedida desde navegadores modernos y adaptada para uso en computadores y dispositivos móviles.

El sistema será desarrollado en entorno web utilizando:

    o	Frontend: Angular 20
    o	Backend: Laravel 12 con API REST
    o	Base de datos: MySQL 11.2 XE
    o	Gestión de seguridad: Laravel Sanctum para control de tokens de autenticación
    o	Despliegue: Arquitectura cliente-servidor sobre entorno local o nube privada
